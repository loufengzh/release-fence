# release-fence: руководство

Инструмент проверки качества ZIP-релизов: обязательные файлы, запрещённые пути,
ограничения размера и детерминированная опись с SHA-256. Требуется Python 3.10+
с zlib; во время работы используются только модули стандартной библиотеки.
Архив не распаковывается на диск, его содержимое не исполняется, сеть не нужна.

## Быстрый запуск

```sh
python -m pip install .
python examples/make_demo.py
release-fence check examples/demo.zip --policy examples/policy.json
release-fence scan examples/demo.zip > before.json
release-fence diff before.json before.json
```

`required` содержит точные относительные пути файлов с учётом регистра, не шаблоны.
`forbidden` использует Python `fnmatchcase`: `*` совпадает и с `/`, и с начальной
точкой; у `**` нет отдельной рекурсивной семантики. `*.pyc` найдёт файл на любой
глубине. Корневой каталог архива автоматически не удаляется.

По умолчанию: `max_files` = 1000, `max_total_bytes` = 67108864,
`max_member_bytes` = 16777216. Лимиты байтов проверяются по реально
декодированному содержимому. Неизвестные поля, повторные ключи JSON и неправильные
типы отклоняются. Встроенных языковых профилей нет; правила задаёт ваш проект.

Коды завершения: 0 — полное сканирование, успешная проверка или отсутствие
изменений; 1 — нарушение путей в `check` или изменения в `diff`; 2 — ошибка ввода,
неподдерживаемый ZIP, превышение ресурса или ошибка I/O. `scan` записывает нарушения
путей, но возвращает 0. При превышении лимита неполная опись не выводится.

## Границы поддержки

Только stored/deflated ZIP; без TAR, ZIP64, шифрования, нескольких томов,
самораспаковывающегося префикса и символических ссылок. Жёсткие пределы:
64 MiB на архив, 8 MiB на центральный каталог, 10000 записей. Абсолютные пути,
обратные слеши, `..`, дубликаты и файлы вместо родительских каталогов запрещены.
Unicode не нормализуется, регистр не сворачивается.

Записи файлов и сравнение содержимого игнорируют время, права, сжатие и пустые
каталоги. Явные записи каталогов могут изменить список нарушений запрещённых путей. `diff` сравнивает только
содержимое и размер обычных файлов, а не нарушения политики. Переименование —
удаление и добавление. Это не антивирус, поиск секретов, проверка подлинности или
полный валидатор стандарта ZIP. Для недоверенных входов нужны отдельные ограничения
ОС и изоляция. Подробности: [основная документация](../README.md).

Тесты: `PYTHONPATH=src python -m unittest discover -s tests -v`.
